# 設計・検証メモ

## 構成

- `src/api/nikkeApi.ts`: API通信、共通形式への変換、BlablaLink ID抽出、非破壊マージ
- `src/storage.ts`: localStorageスキーマv4、初期値、インポート検証
- `src/data/communityTeams.ts`: 出典確認済みの完成編成、運用注意、元の枠と対応付けた掲載元の代替例
- `src/data/releaseOrder.ts`: 実装日を確認した静的な新着順
- `src/rules/growth.ts`: BlablaLink取込値の参照と育成目標との差分
- `src/pages/`: ホーム、ニケ一覧、ニケ詳細、編成、設定。ニケ詳細は育成・装備／OL・推奨の3タブに分離し、一覧の絞り込みとスクロール位置を維持する
- `public/sw.js`: アプリシェルと公開マスターデータのキャッシュ。`/api/user/` は対象外

API一覧は起動時に1回だけ取得し、検索と絞り込みは取得済み配列だけで行います。詳細は専用画面を開いた時だけ取得し、画面を閉じるまで保持します。個人入力だけをlocalStorageへ保存し、画像や全キャラ詳細JSONは保存しません。

## 保存と取り込み

保存データは `nikke-compass:data`、スキーマバージョンは4です。BlablaLink取り込み値は `record.imported` に保存し、現在値の表示はこの取込値を優先します。旧版の手入力値はバックアップ互換のため削除せず保持しますが、現在値として編集するUIは提供しません。共有URLは保存せず、openidはバックアップ対象外の接続専用キーに保存します。ユーザーAPIの内部IDは図鑑IDと異なるためresourceIdで照合します。

## 編成支援の範囲

編成はGameWith、Prydwen、NIKKE.GGの公開攻略で更新日を確認した5人の完成形を静的に複数収録し、同一用途では所持数が多い順に表示します。キャンペーンはGameWithの最新汎用完成編成とPrydwenの高戦力差向け掲載例を併記し、汎用編成をキャンペーン専用・フルオート保証とは表現しません。アプリはメンバーの選出、欠員補完、独自の代替提案、ダメージ計算を行いません。BlablaLinkの取込値は所持数と宝もの解放状況の表示にだけ使います。

未所持メンバーも掲載編成のまま目標として表示します。代替は掲載元に明記されたものだけを元の枠へ対応付け、候補ごとの所持状況とともに表示します。掲載順が推奨配置とは確認できない場合は「掲載順」と明記します。ボス固有操作は要点と原文リンクを示しますが、育成度、操作精度、ダメージ、クリアを保証しません。「レッドフード」と「ラピ：レッドフード」はresourceIdで別キャラとして扱います。

ニケ一覧はGachaTrackerの公開実装日を2026-11-03に確認してresourceIdへ静的に対応付け、新しい順に並べます。アプリ起動時の追加通信はありません。順序表にない新キャラは暫定的に先頭へ置き、次のデータ更新で実装日順を確定します。

スキル目標はNikkers、Prydwen、NIKKE.GGを2026-11-04に照合し、同じ値が複数ソースで頻出する場合に優先採用します。まだ一致を確認できないキャラはNikkers値を「単一ソース参考」と明記し、複数ソース一致と見せません。紅蓮：神殺は実装後のNIKKE.GGとTL&Dを2026-11-05に照合し、10/10/10へ更新しています。

オバロ推奨はNikkersとNIKKE.GGのキャラ別記載を2026-11-04に確認し、頻出する効果と目安をresourceIdで静的に対応付けます。紅蓮：神殺は実装後の4ソースを2026-11-05に照合し、一致した有利コード4枠・攻撃力4枠だけを必須目標、評価が分かれた残りを追加候補にしています。ブラウザ実行時には攻略サイトへ通信せず、未確認resourceIdへ推測を流用しません。未確認は `reviewStatus` で明示し、空欄を厳選不要として扱いません。機能改修とは別に、新キャラ追加・既存ビルド変更時をデータ更新タイミングとします。

オバロ目標は取込済み効果名と推奨効果を照合し、枠数目標と合計％目標を分けて端末内で判定します。「付けない」効果が存在する場合は非推奨として未達にし、必須目標とともに育成対象の達成状況へ反映します。数値を取得できない割合目標は推測せず確認待ちとします。ランク12〜14は青字、ランク15は黒帯として表示し、装備固有名と装備IDは画面に出しません。推奨情報の起動時通信や定期ポーリングは行いません。

## 重点検証

- 390×844と430×932で横方向にはみ出さず、下部ナビがホームインジケーターを避ける
- 文字入力が16px以上でSafariの自動拡大を起こしにくい
- 検索、5種絞り込み、所持・育成切替が即時反映される
- 再読み込みでlocalStorageが復元される
- JSON書き出し→読み込みで復元され、上書き前に確認が出る
- 各用途の掲載編成が5人固定で、所持状況によってメンバーが変わらない
- ニケ一覧が実装の新しい順または戦闘力の高い順に並び、検索・絞り込み後も順序を維持する
- ID 447001（レッドフード）と201601（ラピ：レッドフード）を別レコードとして扱う
- API失敗時に保存済みレコードと内蔵最小カタログで操作を継続する
